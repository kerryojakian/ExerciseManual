# ExerciseManual
This is a basic software package for creating and managing homework sets and tests (intended for math and computer science).  The philosophy of this project is summarized in the following points:
- Meant to facilitate the creation of Latex documents which contain exercises, but allow the creator to build any Latex freely around that.
- It is centered around a single Latex document which serves as the data base of exercises.
- The exercises in the data base of problems are meant to be a large collection of curated exercises (i.e. yes AI can create gobs of exercises, but are they the exact types of problems you want, and have they been checked, and so on).

For details on how to use this package, read the DetailedDescription.

*Disclaimer: I began small, and this thing grew! It is surely buggy in places, it is definitely clunky, and the code has taken a messy turn.  Though this package is already involved (by my standards!), I consider this current development to be something like a messy logical core of what could some day be a much improved package.*
