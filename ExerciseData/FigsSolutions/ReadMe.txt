A way to get these figures.

- Open the "Snip and Sketch" app (NOT via Windows/Shift/S)
- Do "new" and select image
- Save the image (right side)
- Open the image in PDF Annotator (with the option of "adjust page size to image size") so now it is PDF
- Do Save AS on this PDF with the desired name.
- Do all files in the appropriate folder to make faster.
- Put \solfig{JUST CODE}
